Connectors

Works in the services you use.

GitHub, Linear, Notion, Atlassian, Sentry, Hugging Face and DeepWiki are in the list. Any other service that speaks the Model Context Protocol (MCP) is added by pasting its address.

You sign in on the service’s own page, as you would for any app. Resident never sees your password, keeps its access in the iPhone’s Keychain and renews it without asking again.

Then ask in plain words. Find my open issues. Close this one. Comment on that pull request.

Tools

Tools of its own, on the device.

Everything else it works with runs on the iPhone itself. There is no key to buy, and no account of ours to make.

The web

Search and page reading run on the phone, with no account or key. A long page is ranked against your question, so the model reads the passages that matter.

A code sandbox

A JavaScript interpreter with no network and no access to your files. Arithmetic, dates and data are computed, not guessed.

Files

The tools a coding agent has: list, search, read, edit and write. They work on Resident’s folder in the Files app, so you can put files in and take out what the model wrote.

Code and pull requests

With GitHub connected, the agent copies a repository into that folder, changes the code and opens a pull request for you to review. The branch and the commit are made for it.

Calendar and Reminders

The agent reads and changes your calendar and reminders through iOS itself, on the device. Ask for “tomorrow at 5” or “Friday” and it lands on the right day.

Documents and photos

Attach a PDF, a document or a photo. A long document is read a part at a time, and text in scans and screenshots is recognized on the device.

How it works

The harness matters more than the model.

A model small enough for a phone can reason well, and is easily overwhelmed. Whether it gets real work done depends on what it is shown and on what it is allowed to write. Resident controls both, and that is where the reliability comes from.

Context: what the model is shown

Tools appear when they are needed

A connected service is one line in the prompt until a request needs it. Linear’s server offers about 70 tools; the model is handed the few that fit the request, not all of them.

Tool definitions are trimmed

Services describe their tools for large models. Resident cuts each description and schema down to what it takes to make the call, which nearly halves what the opened tools cost.

Tool results are made to fit

Twenty issues with pages of description would fill the context. Resident shortens the long parts first, keeps every item, and says so when something was left out.

Nothing is read twice

Each step feeds the model only what is new. Old tool results shrink as a chat grows, and a long chat is summarized behind the scenes, so the model’s time goes to your question.

Control: what the model may write, and what happens when it slips

A broken tool call cannot be written

Once the model starts a call, a grammar admits only a tool that exists and arguments that fit its schema. Text and thinking stay free; the call itself cannot come out malformed.

Thinking has a budget

Thinking is set per chat, from off to high. The lower levels are capped, and a model that still thinks itself out of room is asked again with thinking off.

Mistakes come back with the fix

A call that fails returns what the tool expects. A tool called by the wrong name brings the closest real ones. A repeated call is refused. The model corrects itself instead of looping.

A long job is not lost

The chat is saved after every step. A reply cut off when you leave the app carries on when you come back, and one that uses all its steps says what is left and continues with a tap.

How we check all this: a public suite of 423 scored test requests that any model can be run through. On its last full run, LFM3 1.7B passed 382 of the 398 the suite had then.

What it does

An agent, not a chat box.

Remembers what matters

Keeps a short list of lasting facts you mention and uses them in later chats. Read it, edit it or switch it off.

Learns how you work

Turn something it just did into a skill with one tap. You see and approve every skill before it is kept.

Listens

Dictate instead of typing. A speech model on the device turns your voice into the message.

Agents

Good defaults, yours to change.

An agent is a set of instructions, the tools it may use and how hard it thinks. Start with the Assistant, switch to the Coder, or make your own for the things you do often.

The defaults are chosen to work. The numbers are there when you want them: temperature and reply length for an agent, sampling for a model, thinking for a chat.

Automation

Runs from Shortcuts, with the app closed.

The Ask Resident action takes a message, an agent and a model, and hands back the reply as plain text. Chain it with other actions, or run it on a schedule.

A job that takes a while shows its progress as a Live Activity, with a button to stop it. A model on the phone runs more slowly off screen, so a second action, Wait for Resident, collects a reply that needs longer.
